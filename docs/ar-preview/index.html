Arabic RTL — first draft previews

Every page of the shop in Arabic, right to left, next to its English twin. Each file is the page exactly as the shop renders it, saved with its styles, fonts, pictures and scripts inside, so it opens offline: tabs, accordions, carousels and arrows, the mobile menu, the cart panel, Read more. Nothing here talks to the shop — buttons that need the server (add to bag, place order) do nothing.

Seen at 390px and 1280px. Open any file and narrow the window to phone width. Round 3: the Arabic header is the real one now — the Arabic name with the lotus on its right, the search box, its suggestions and results in Arabic (hybrid search: Arabic or English words both find products). Screenshots and measurements: docs/lane-ar-shots/round2/.
