The icons, set by set

Four sets of simple line icons, one weight and one colour each, shown at 96px and at 56px (the smallest phone size). The presentation and line colour follow the settings above.

How it would ship

  • One inline SVG sprite of the chosen set (about 3 KB), printed once; each tile is <svg><use href="#…"/></svg>. No image requests.
  • CSS scroll-snap does the swiping. Arrows and dots use an IntersectionObserver and scrollIntoView; mouse drag uses the pointer's own movement. Nothing measures the page.
  • Autoplay off means no timer at all. When on, it runs only while the row is on screen, the tab is visible and nobody is touching it.
  • The seven links are fixed addresses, so the section adds no database query.
