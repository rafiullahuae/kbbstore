The artwork

Seven drawings, one per concern, in three styles. Each is hand-built SVG, so it stays sharp at any size and weighs a couple of kilobytes. The number under each is its own size plus the gradients it uses.

How it would ship

  • One inline SVG sprite printed once in the section; each tile is <svg><use href="#…"/></svg>. No image requests.
  • CSS scroll-snap does the swiping. Laptop arrows jump to the first hidden tile with scrollIntoView; nothing measures the page.
  • The seven links are fixed addresses, so the section adds no database query.
