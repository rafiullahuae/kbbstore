### reading the intrinsic column

`naturalWidth` is DENSITY-CORRECTED once a srcset has resolved: a 200px file
chosen for a 66px box reports 66, not 200. So the "waste" column is the ratio
the browser itself sees, and 1.0 means the file carries exactly the pixels the
box can show. Before the change, the same column read 1000 against a 52px box.
The filename in the `fetched` column is the honest record of which file arrived.
