### reading the PAINTED column

The `.gthumb` BOX has always been a 66px square. Under object-fit:contain the
picture inside it is scaled until it FITS, so a 9:16 photograph paints a narrow
stripe and a square one fills the tile — which is what the owner photographed.
Under cover it is scaled until it FILLS and the box crops it, so PAINTED equals
the box for every shape. That column, not the box column, is the answer to
"make them square".

`naturalWidth` is DENSITY-CORRECTED once a srcset has resolved, so the file
shape column reads the CSS pixels the chosen candidate is worth, not its stored
pixels. The filename in `fetched` is the honest record of which file arrived.
